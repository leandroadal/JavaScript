# Express

O Express tem o objetivo de simplificar a criação de servidores HTTP, rotas, middlewares e o tratamento de requisições e respostas. O framework abstrai funcionalidades do módulo HTTP nativo do Node.js, reduzindo a complexidade do código e tornando o desenvolvimento mais produtivo.

## Principais funcionalidades

O Express permite:

* criação de servidores web;
definição de rotas;
* tratamento de requisições HTTP;
* utilização de middlewares;
* criação de APIs REST;

## Instalação

`npm i express`
