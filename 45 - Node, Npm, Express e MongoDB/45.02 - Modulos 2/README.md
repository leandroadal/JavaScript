# Navegando nas pastas

## Pasta atual

O `.` é a pasta atual

### A partir dessa pasta

`./`

### Exemplo 1

`'./D/mod'` caminho `diretório atual -> D -> mod`

## Regressar

O `..` volta uma pasta.

### Exemplo 2

Para chegar `mod.js` a partir do `mod2.js` é necessário fazer o seguinte caminho:

`'../../../D/mod'` caminho `C -> B -> A -> Raiz -> D -> mod`
