# Middlewares

Middleware é uma função executada entre a requisição do cliente e a resposta do servidor.

Requisição → Middleware → Rota → Resposta

## Usos comuns

* modificar requisição;
* modificar resposta;
* validar dados;
* autenticar usuários;
* registrar logs;
* bloquear acesso;
* encerrar resposta;
* chamar próximo middleware.
